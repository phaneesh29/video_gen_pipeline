Title: Two Sum: Optimal Hash Map Strategy
Topic: Data Structures & Algorithms / Array & Hash Table

Problem Statement:
Given an array of integers nums = [2, 7, 11, 15] and target = 9, return the indices of the two numbers that add up to target.

Core Visual & Algorithmic Story:
1. Problem Introduction:
   We are given the array [2, 7, 11, 15] and a target sum of 9. We need to find the two indices whose values sum up to 9.

2. The Brute Force Bottleneck:
   The naive approach compares every pair using nested loops. For an array of size N, this takes O(N²) quadratic time, which times out on large test cases.

3. The Optimal Insight (The Complement):
   Instead of searching every future number, turn the question around. For any current number, we need complement equals target minus current number.

4. Step 1 (Index 0, value 2):
   We visit index 0 with value 2. Target 9 minus 2 means we need 7. We check our hash map. 7 is not found, so we store 2 at index 0.

5. Step 2 (Index 1, value 7):
   We move to index 1 with value 7. Target 9 minus 7 means we need 2. We check our hash map, and 2 is found at index 0!

6. The Match and Return:
   Match found! We pair index 0 and index 1 because 2 plus 7 equals 9. We immediately return indices [0, 1].

7. Complexity Analysis:
   By storing visited numbers in a hash map, we solve the problem in a single pass: O(N) linear time and O(N) space.
